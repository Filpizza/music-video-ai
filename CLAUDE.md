## Цель проекта

Автоматический конвейер (pipeline) для создания **музыкальных клипов для YouTube**.
Планируемая длина роликов — 1–2 часа. Выпуск каждые 2–3 дня. Серьёзная монетизация.

Полный поток работы задуман так:
1. Пользователь пишет промпт → ИИ (Gemini) улучшает его.
2. Генерируется музыка (Suno) + текст песни.
3. По музыке строится план визуальных сцен (Gemini).
4. Для каждой сцены генерируется изображение (Flux / fal.ai).
5. Изображение оживляется в видеоклип 8 сек (Kling или Veo).
6. Каждый клип проверяется на галлюцинации (Gemini Vision).
7. Клипы склеиваются в финальный ролик (FFmpeg / MoviePy).
8. Собирается черновик для CapCut (через VectCutAPI) для финального монтажа.
9. Генерируются название, описание, теги, превью для YouTube.

## Ключевой принцип: режим dry_run

Пользователь — новичок и боится случайно потратить реальные деньги на API.
**Поэтому весь код должен поддерживать два режима**, переключаемых в `.env` (`MODE`):

- `dry_run` (по умолчанию) — НИКАКИХ платных вызовов. Вместо реальных API
  создаются заглушки (например, тихий MP3 нужной длины, placeholder-картинка,
  чёрный видеоклип). Всё бесплатно. Нужно чтобы прогнать весь pipeline и убедиться
  что логика работает.
- `production` — реальные вызовы API (тратит деньги). Подключаем в самую последнюю
  очередь, когда всё проверено на заглушках.

Каждый новый модуль ОБЯЗАТЕЛЬНО делай с поддержкой обоих режимов. Читай `config.MODE`.

## Что уже сделано (текущее состояние)

- **config.py** — центральные настройки. Читает `.env`, определяет режим (dry_run/
  production), хранит пути к папкам (output, work, music, images, clips, assets),
  настройки видео (1920×1080, 30fps, клип 8 сек). Функция `check_config()` печатает
  статус. Папки создаются автоматически. ✅ Проверено, работает.

- **music_generator.py** — генерация музыки. В dry_run создаёт тихий MP3 нужной длины
  через FFmpeg (функция `_generate_dry_run`). В production вызовет Suno (пока заглушка
  `NotImplementedError`). Главная функция `generate_music(prompt, duration_sec)`
  возвращает dict с audio_path, lyrics, title, duration. ✅ Проверено, работает.

- **brain.py** — "мозг" на Gemini. Две функции: `improve_prompt(user_prompt)` улучшает
  промпт; `plan_scenes(music_prompt, lyrics, num_scenes)` строит план сцен. Использует
  бесплатную модель gemini-1.5-flash. Если `GEMINI_API_KEY` пустой — возвращает
  заглушки. ⚠️ Ещё не запускалось пользователем — нужно проверить.

- **.gitignore** — защищает секреты (.env), пропускает venv, work, output.
- **README.md** — описание проекта.

## Что делать дальше (план)

1. **Сначала** проверь что `brain.py` работает: запусти `python brain.py` в активном
   venv и покажи результат. Убедись что ключ Gemini рабочий.
2. Затем построй следующие модули pipeline (каждый с dry_run заглушкой):
   - `image_generator.py` — генерация изображений (dry_run: цветная placeholder-картинка
     через Pillow/FFmpeg; production: Flux через fal.ai).
   - `video_generator.py` — изображение → видеоклип (dry_run: клип из статичной картинки
     через FFmpeg; production: Kling/Veo).
   - `quality_checker.py` — проверка клипов на галлюцинации (dry_run: всегда "прошло";
     production: Gemini Vision).
   - `assembler.py` — склейка клипов + аудио в финальный ролик (FFmpeg/MoviePy).
   - `main.py` — оркестратор: связывает все модули в единый pipeline.
3. Прогони весь pipeline в dry_run от начала до конца на коротком тесте (например,
   ролик 30 секунд), убедись что на выходе получается видеофайл.
4. Только ПОТОМ подключаем реальные API по одному, начиная с самых дешёвых.
